# neutralinojs-3js-wasm
> Neutralinojs with Three.js and WASM(Rust)!

## Quick Start
```
neu create myapp --template aoaochan/neutralinojs-3js-wasm
```

## Requirements
- Rust
- wasm-pack: `cargo install wasm-pack`
- Node.js v24+

## Scripts
- npm run dev
- npm run build
